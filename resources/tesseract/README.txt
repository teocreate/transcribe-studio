Tesseract OCR 5.4.0 (UB Mannheim Windows build 5.4.0.20240606), bundled by
Transcribe Studio to read scanned PDFs and images on the Markdown tab.

Contents: tesseract.exe and the DLLs it loads (Leptonica 1.84.1 and its image
libraries), taken unmodified from
https://github.com/UB-Mannheim/tesseract/releases/tag/v5.4.0.20240606
except that DWARF debug sections were removed from libtesseract-5.dll.
Language data: tessdata_fast (eng, rus, spa, fra) from
https://github.com/tesseract-ocr/tessdata_fast

Tesseract and the language data are licensed under the Apache License 2.0
(LICENSE.txt). Leptonica is under a BSD-2-Clause-style license; the image
