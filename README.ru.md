# Transcribe Studio

Десктопное приложение для Windows: локальная транскрибация аудио и видео
моделями [Whisper](https://github.com/openai/whisper) от OpenAI (через
faster-whisper) и конвертация любых документов, сканов и изображений в
Markdown через [MarkItDown](https://github.com/microsoft/markitdown) от
Microsoft и [Tesseract OCR](https://github.com/tesseract-ocr/tesseract).
Всё работает на вашем компьютере, ничего не уходит в облако.

## Установка

Готовые сборки — во вкладке [Releases](../../releases): установщик (ставит
для всех пользователей в `C:\Program Files\Transcribe Studio`, просит права
администратора, OCR внутри) и portable-архив (папку `tesseract` держите рядом
с exe). При первом запуске кнопка «Установить всё» создаст собственное
Python-окружение и скачает рекомендуемую для вашего железа модель — нужен
интернет и Python 3.11 или новее с [python.org](https://www.python.org/downloads/).
Всё скачанное хранится в `%LOCALAPPDATA%\TranscribeStudio`.

Rust + Tauri для окна, процессов, загрузки моделей и настроек; Python — два
коротких воркера, которые общаются с Rust построчным JSON.

```
┌─ окно (WebView2) ──────────────────────────────┐
│  ui/index.html · styles.css · app.js           │
└──────────────┬─────────────────────────────────┘
               │ Tauri IPC (команды + события)
┌──────────────┴─────────────────────────────────┐
│  src/main.rs      команды и окно                │
│  src/jobs.rs      запуск воркеров, отмена       │
│  src/models.rs    каталог моделей, загрузка с HF│
│  src/pyenv.rs     поиск и настройка окружения   │
│  src/power.rs     запрет засыпания              │
│  src/settings.rs  настройки на диске            │
└──────────────┬─────────────────────────────────┘
               │ stdout: по одному JSON на строку
┌──────────────┴─────────────────────────────────┐
│  py/transcribe_worker.py   faster-whisper       │
│  py/markdown_worker.py     markitdown           │
└────────────────────────────────────────────────┘
```

## Что умеет

**Вкладка «Транскрибация»**

- Очередь файлов: перетаскиванием или через диалог. Аудио и видео —
  m4a, mp3, wav, flac, mp4, mkv и всё остальное, что понимает FFmpeg.
- Выбор модели, языка, задачи (расшифровка или перевод на английский),
  ширины поиска, числа потоков CPU, типа вычислений и VAD-фильтра тишины.
- Подсказка декодеру — список имён и терминов, которые встретятся в записи.
- Живой прогресс: процент, позиция в записи, скорость относительно реального
  времени, оценка остатка и поток распознанного текста.
- Форматы на выходе: TXT, SRT, VTT и MD. Markdown пишется сразу с
  метаданными и тайм-кодами, а не как сплошная простыня.
- Запрет засыпания компьютера на время работы.
- Опционально — дополнительно прогнать готовый TXT через markitdown.

**Вкладка «Markdown»**

- Конвертация любых файлов, которые понимает markitdown: PDF, DOCX, XLSX,
  PPTX, HTML, CSV, EPUB, изображения, архивы.
- Предпросмотр результата с переключением «Просмотр / Исходник», копированием
  и переходом к файлу в проводнике.
  При пакетной конвертации клик по строке очереди открывает её результат.
- Сканы и картинки распознаются встроенным Tesseract OCR (`resources/tesseract`,
  ставится установщиком; portable находит папку `tesseract` рядом с exe).
  В PDF распознаются только страницы без текстового слоя. Языки — язык
  интерфейса, язык записи и английский. Пустой результат считается ошибкой.

**Настройки**

- Менеджер моделей: восемь вариантов Whisper с размером, оценкой скорости и
  качества, загрузкой с прогрессом и скоростью, отменой и удалением.
  Прерванная загрузка докачивается с того же места, готовые файлы сверяются
  по размеру и SHA-256 из API Hugging Face.
- Рекомендуемая модель подбирается под железо (потоки CPU и объём ОЗУ, см.
  `models::recommend`); на первом запуске она же выбирается по умолчанию.
- Состояние Python-окружения и кнопка, которая его создаёт и чинит. На первом
  запуске — одна кнопка «Установить всё»: окружение и рекомендуемая модель.
- Язык интерфейса: English, Русский, Español, Français. По умолчанию — язык,
  выбранный в установщике, иначе язык Windows, иначе английский.
- Оформление: системное, светлое, тёмное.

## Языки

Строки окна — в `ui/locales/<код>.js` (одинаковые ключи во всех файлах),
движок — `ui/i18n.js`, разметка ссылается на ключи через `data-i18n*`.
Ошибки и логи, которые рождаются в Rust, — таблица в `src/i18n.rs`; воркеры
получают язык в задании (`ui_language`) и переводят свои сообщения сами.
Новый язык: файл в `ui/locales`, `<script>` в `index.html`, кнопка в
«Общие», столбец в `src/i18n.rs`, словари воркеров и язык NSIS в
`tauri.conf.json`. `node tests/locales.test.mjs` поймает пропущенные ключи.

## Сборка

Нужны Rust (MSVC toolchain) и WebView2 (есть в Windows 11 из коробки).

```powershell
cargo build --release                 # просто exe
cargo tauri build                     # + установщик NSIS
```

Интерфейс вшивается в бинарник на этапе компиляции, поэтому после правки
файлов в `ui/` нужна пересборка.

## Проверки

```powershell
node tests/markdown.test.mjs          # рендерер Markdown
node tests/locales.test.mjs           # словари интерфейса согласованы
cargo test                            # язык, рекомендация модели
pwsh tools/shot.ps1                   # собрать, запустить, снять скриншот
pwsh tools/e2e.ps1                    # сквозной прогон транскрибации
pwsh tools/e2e_md.ps1                 # вкладка Markdown
pwsh tools/e2e_model.ps1              # загрузка модели
pwsh tools/e2e_cancel.ps1             # остановка задачи и окружение
pwsh tools/e2e_lang.ps1               # переключение языка интерфейса
pwsh tools/e2e_resume.ps1             # отмена, докачка и проверка хэша
pwsh tools/e2e_md_multi.ps1           # пакетная конвертация, сканы, превью
python tools/make_icon.py             # перегенерировать иконки
```

Скрипты из `tools/` кликают по настоящему окну и складывают скриншоты в
`%TEMP%`. Координаты задаются в CSS-пикселях и масштабируются под DPI.

## Модели

Берутся с Hugging Face в формате CTranslate2 и кладутся в локальный каталог,
который передаётся faster-whisper как путь, — так приложение само управляет
загрузкой и показывает честный прогресс.

| Модель | Размер | Комментарий |
|---|---|---|
| Tiny / Base | 75 / 145 МБ | Черновики и быстрые проверки |
| Small | 484 МБ | Разумный минимум для речи не на английском |
| Medium | 1.5 ГБ | Запасной вариант |
| Large v3 Turbo | 1.6 ГБ | Качество Large v3, вдвое меньше; рекомендуется при 8+ ГБ ОЗУ и 6+ потоках CPU |
| Distil Large v3 | 1.5 ГБ | Быстрая, но слабее вне английского |
| Large v2 / v3 | 3.1 ГБ | Максимум качества, на CPU очень медленно |
